# Аудит источников (этап 0)

Статус на 1 октября 2026: **ни один реальный источник не подключён и не проверен.** Работает только
демонстрационный каталог (`tests/fixtures/feeds`, вымышленные магазины на доменах `.example`).

Кандидаты из предыдущего исследования — Lamoda, BRANDSHOP, Love Republic, Befree, STREET BEAT.
Наличие страницы affiliate-программы не означает доступа к фиду для нашего проекта.

## Что получить по каждому источнику до интеграции

| Вопрос | Как проверить | Куда записать |
|---|---|---|
| Разрешение на использование фида, текстов и изображений | письменное согласие / условия программы | этот файл, раздел источника |
| Формат и режим (full / delta), частота обновления | образец фида + документация | `feed_sources.format`, `is_full_snapshot`, `refresh_interval`, `stale_after` |
| Модель SKU/вариантов: что такое offer, есть ли group_id, где цвет | образец | маппинг адаптера (`mapping_version`) |
| Размерные системы и таблицы брендов | образец, `param unit` | словарь размеров |
| GTIN/штрихкоды, код модели производителя, код цвета | образец | правила дедупликации |
| Домены товаров, изображений и tracking-ссылок | образец | `merchants.allowed_domains`, `affiliate_domains` |
| Объём: записи, модели, варианты, доля без наличия | `fashion-worker import` → `import_runs.audit` | раздел источника |

## Как провести аудит образца

1. Положить URL образца в секрет (`FEED_URL_<ИСТОЧНИК>`), добавить хост в `FEED_ALLOWED_HOSTS`.
2. Завести merchant/feed_source (аналогично `fashion_worker/seed.py`) с `enabled=true`.
3. `fashion-worker import <source>` — при сомнительном объёме run останется в статусе `held`, каталог не изменится.
4. `fashion-worker audit <run_id>` — null-доли полей, размеры, бренды, категории, причины карантина.
