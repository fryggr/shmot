# Оценка качества (этап 4)

Здесь появятся `queries.jsonl` (100 русских запросов, 70 tuning / 30 holdout), `judgments.jsonl`
(слепая оценка 0–3 пула top-20 режимов A/B) и `report.py` (nDCG@10, полезный результат в top-5,
zero-results, нарушения hard filters, bootstrap-интервалы) — см. раздел 12 ТЗ.

На этапе 1 файлы намеренно не созданы: оценивать нечего, пока нет режима B и реального каталога,
а заглушки с выдуманными суждениями вводили бы в заблуждение.
